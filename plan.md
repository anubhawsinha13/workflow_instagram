The Workflow ArchitectureStage 1: Research (Perplexity API)Goal: Generate a factual or creative story based on a topic.Prompt: "Research the history of [Topic] and provide a compelling, narrative-style story of approximately 300 words suitable for a video script."Stage 2: Scripting & Formatting (OpenAI API)Goal: Transform the Perplexity output into a structured script with specific scenes, text overlays, and voiceover cues.Prompt: "Take the following story: [Perplexity Output]. Break it into 5 distinct scenes. For each scene, provide: 1) A short text overlay (max 10 words), 2) A descriptive prompt for a background video/image, and 3) The specific voiceover text. Return this in a JSON format."Stage 3: Video Assembly (Creatomate API with ElevenLabs)Goal: Use the Creatomate /renders endpoint to merge the script components into a final video.Voiceover Integration: Creatomate allows you to use ElevenLabs directly within the template. You will pass the script text and voice ID via the modifications parameter.Implementation PlanStep 1: Set up the Creatomate TemplateIn the Creatomate editor, create a template that includes:A Text Element (e.g., named "Primary-Text") for captions.A Video/Image Element (e.g., named "Background-Media") for the visuals.An Audio Element with the source set to an ElevenLabs provider.Step 2: The API Integration ScriptYou can use a Python or Node.js script to chain these services. Below is a conceptual structure for the final API call to Creatomate.Endpoint: POST https://api.creatomate.com/v2/rendersRequest Body (JSON):JSON{
  "template_id": "YOUR_TEMPLATE_ID",
  "modifications": {
    "Primary-Text.text": "The text overlay from OpenAI",
    "Background-Media.source": "https://url-to-your-video.mp4",
    "Voiceover.source": "elevenlabs",
    "Voiceover.settings": {
      "text": "The voiceover script from OpenAI",
      "voice_id": "YOUR_ELEVENLABS_VOICE_ID",
      "api_key": "YOUR_ELEVENLABS_API_KEY"
    }
  }
}
